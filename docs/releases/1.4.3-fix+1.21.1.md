# Summy Enchantment 1.4.3-fix+1.21.1

> Minecraft 1.21.1 · Fabric Loader 0.20.1+ · NeoForge 21.1.265+ · Java 21
>
> 修复附魔规则与切换世界后的查询，完善 NeoForge 可选联动。网络协议为 `9`。
>
> 客户端和服务端使用同一 SE 版本，`mods/` 中只放对应加载器的一份 SE。

## 修改

- **SR 联动提示（NeoForge）**：安装 SR 后，旧版普通攻击也可能输出「SR 近战兼容已生效」，让人误以为 SR 技能已触发联动。本版将近战结算和兼容提示分开，只在 SR 技能实际进入联动结算时输出这条日志。
- **SR 注入配置（Fabric）**：旧版 Fabric 包携带 SR 联动配置，发现相关类时可能尝试挂接该平台未提供的 SR 技能。本版移除了这套专用注入，并将普通近战的命中后效果归入共用结算。

## 修复

- **无限与经验修补**：开启共存选项后，铁砧、`/enchant` 和随机附魔按同一规则判断这一对附魔。无尽箭袋与无限仍按各自的互斥规则判断。
- **锋利Plus**：关闭锋利Plus 开关时可与原版锋利配对。亡灵杀手与节肢杀手按原有互斥规则判断。
- **保护上限**：启用保护等级扩展后，从配置读取 `protection_max_level`。默认值为 5，可在配置文件中设置为 1～10。
- **切换世界**：退出单人世界、断开服务器或停止服务端时清理对应的附魔注册表引用，使重连后的查询使用当前会话的附魔定义。

## 兼容

- **SR / SRA（NeoForge）**：以 Summy Reliquary `2.0.0-neoforge+` 为可选联动基线，搭配 Summy Reliquary: Apocrypha `0.1.4-neoforge` 与 Curios `9.5.1+1.21.1`。已分别用 SR `2.0.0-neoforge` 和 `2.0.1-neoforge` 实测「遁入暗影」基础斩击、强力斩击及投掷长矛命中。
- **Apothic Enchanting（NeoForge）**：独立附魔模块安装时，由它负责铁砧费用、界面显示和扣费。卸载并重启后恢复 SE 的铁砧设置。SE 生命修补有可修装备时优先，否则由上游生命修补接续。实测独立模块 `1.6.4` 和完整 Apotheosis `8.9.0`。
- **KubeJS（NeoForge）**：服务端 `ServerEvents.loaded` 可以读取当前世界的附魔定义。已复验查询、脚本隔离与七类结算事件。
- **Backported Spears（NeoForge）**：`1.8.0` 左键刺击和蓄力冲刺专项通过。
- **Fabric**：可选联动包括 Backported Spears `1.8.0` 和 Mod Menu。
