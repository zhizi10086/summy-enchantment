# Summy Enchantment 1.4.0

**Minecraft 1.20.1 · Fabric + Forge**

1.4.0 将 KubeJS 兼容升级为安全的查询、服务端只读事件与配置读取接口，并加入破空之愿与本能释放的双向互斥。

## KubeJS

- 服务端 `SummyEnchantment` 保留原有九个方法，最终提供 43 个公开方法。
- 新增附魔元数据、`enchantmentCanApplyTo`、含双向互斥检查的 `enchantmentCanEnchant`、运行时状态、只读配置查询、接口版本与藏剑冷却读取。
- 客户端提供 24 个安全查询，不提供写入、藏剑冷却、事件或服务端权威状态接口。
- 脚本类过滤器默认封锁 SE 内部包，仅服务端脚本可精确加载公共 API；内部战斗与兼容类不能由客户端或启动脚本绕过加载。
- 新增七个服务端只读事件：`meleeSettled`、`lifeShieldChanged`、`deathEyeChanged`、`hiddenBladeConsumed`、`projectileSettled`、`electricArcSettled`、`electricArcFinished`。
- `meleeSettled` 公开攻击侧金额、伤害源与主命中/出其不意分项；箭矢、投掷三叉戟、矛和电刀均有独立观测入口。
- 所有伤害事件统一提供 `attackAmount`；事件武器返回副本，脚本修改不会影响场上原物品。
- KubeJS 可选依赖范围精确限定为 `>=2001.6.5-build.16 <2001.6.6`；开发自检支持通过 Gradle 参数切换 KubeJS/Rhino/Architectury 版本。
- 仓库内置 KJS-only 自检模式和 `verifyKubeJsSelfTest` 自动断言任务，缺少 API、类过滤或事件标记时构建直接失败。
- 测试任务可通过 `-PdevcheckWorldDir` 恢复 `SeDevCheckWorld`；缺少测试世界时会立即提示，而不是等待超时。
- 事件为服务端只读完成事件，不支持取消或替换核心伤害。

客户端脚本初始化早于注册表同步，因此脚本加载当刻查询附魔元数据可能暂时得到空列表；进入世界后再次查询即可获得完整 32 项。

## 附魔调整

- 破空之愿与本能释放双向互斥。
- 两项不能通过附魔台、铁砧、随机组合或 `/enchant` 新增到同一把弓。
- NBT / 数据包强行写入两项的旧物品保留双重效果。

## 内容规模

- 32 个附魔、99 项配置、11 个配置组。
- 网络协议版本 9；客户端与服务端必须使用相同版本。
- KubeJS 仍为可选依赖。

## 验证结果

- Fabric 与 Forge `clean build` 均通过，Forge `verifyMixinTargets` 29 个文件全绿。
- 两树未安装 KubeJS 时均可启动到 `Done`，未加载 KubeJS 插件类。
- Forge 与 Fabric 使用 KubeJS `2001.6.5-build.16`：
  - 服务端查询返回 32 个附魔、99 个配置键、破空之愿 `1 / very_rare / true`，力量倍率读取为 `0.5`。
  - 七个服务端只读事件均实际回调；矛归入 `meleeSettled`，箭矢/三叉戟归入 `projectileSettled`，电刀逐段归入 `electricArcSettled`。
  - 客户端绑定不暴露四类写入/服务端状态方法，也不暴露事件组。
  - 客户端通过 `Java.loadClass` 加载 API 类会被 class filter 拒绝。
- `configBoolean` 只接受布尔配置项；数值项和未知键均安全返回 `false`。
- 玩家登录后执行全部服务端状态查询，无异常；死亡之眼/藏剑默认返回 0，死神祝福双端倍率与复仇倍率默认返回 1，无坚甲物品返回 `Integer.MAX_VALUE`。
- 破空之愿与本能释放双向兼容检查均为 `false`。
- 两树 Fabric / Forge 构建产物均不包含 KubeJS 或 Rhino 依赖类。
- 两树 `verifyKubeJsSelfTest` 均输出 `ALL_OK`，覆盖 43 个服务端方法、24 个客户端只读方法、类过滤隔离和七个事件。
- 开发期第三方依赖只用于离线编译与自检；来源、许可证和 SHA-256 见仓库根 `THIRD_PARTY_NOTICES.md`。

## 安装

### Fabric

1. Minecraft 1.20.1 + Fabric Loader 0.18.4 或更高。
2. 安装 Fabric API。
3. 将 `summy-enchantment-1.4.0.jar` 放入 `mods/`。

### Forge

1. Minecraft 1.20.1 + Forge 47.4.10 或更高。
2. 将 `summy-enchantment-1.4.0-forge.jar` 放入 `mods/`。

升级时只保留一个 SE 版本。
