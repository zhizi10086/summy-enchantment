# Summy Enchantment 1.3.10

**Minecraft 1.20.1 · Fabric + Forge**

1.3.10 聚焦与 Celestial Enchantments、Apotheosis、Majrusz's Enchantments 的同功能附魔兼容，并补齐两种加载器的真实客户端自检与发布许可证。

## 本次更新

- **生命护盾退让**：胸甲带 Celestial `life_shield` 时，SE 停止累积并只撤回自己的护盾份额，不触碰原版或其他模组的吸收。
- **生命修补优先级**：SE 有可修装备时保持严格优先；SE 无可修装备时，Apotheosis 与 Curios 修理正常接管。
- **死神祝福退让**：同一实体带 Majrusz `death_wish` 时，SE 对应造成侧或受伤侧退回 `1.0`，避免重复乘算。
- **许可证修复**：Fabric / Forge 发布 JAR 都带 MIT 正文；Forge 最终 `reobfJarJar` 同时保留 MixinExtras 的许可证。
- **真实客户端自检**：正式包不含自检代码，开发期可通过 `-Pdevcheck` 复现完整兼容场景。
- **内置模组图标**：两个 JAR 都包含最终版铁砧、附魔核心与双箭头图标，并分别通过 `fabric.mod.json` 和 `mods.toml` 声明。

## 内容规模

- 32 个附魔、99 项配置、11 个配置组。
- 网络协议版本 9；客户端与服务端应使用相同版本。
- Fabric 依赖 Fabric API；Forge 使用 Forge 1.20.1。
- Mod Menu、KubeJS 为 Fabric 侧可选依赖。

## 安装

### Fabric

1. Minecraft 1.20.1 + Fabric Loader 0.18.4 或更高。
2. 安装 Fabric API。
3. 将 `summy-enchantment-1.3.10.jar` 放入 `mods/`。

### Forge

1. Minecraft 1.20.1 + Forge 47.4.10 或更高。
2. 将 `summy-enchantment-1.3.10-forge.jar` 放入 `mods/`。

升级时只保留一个 SE 版本。客户端与服务端必须同版本。

## 兼容

- Celestial Enchantments 1.3.7
- Apotheosis 7.4.8
- Majrusz's Enchantments 1.10.8（Forge / Fabric）
- Summy Reliquary、Summy Reliquary: Apocrypha、Backported Spears、KubeJS：可选兼容

## 验证结果

- Forge 真实客户端：Celestial + Apotheosis + Majrusz，12 项检查、0 失败。
- Fabric 原生客户端：Majrusz + Library，4 项检查、0 失败。
- Fabric / Forge 构建通过；Forge `verifyMixinTargets` 29 个文件全绿。
- 正式 JAR 不含 `devcheck`，未打包外部附魔模组命名空间。
