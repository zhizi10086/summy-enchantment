# Summy Enchantment 1.4.3+1.21.1

**Minecraft 1.21.1 · Fabric + NeoForge**

这是 Summy Enchantment 1.4.3 的 Minecraft 1.21.1 平台版本，完成兼容收口、玩家属性、掉落/投射物管线与战斗结算修复；附魔、配置和网络协议规模保持不变。

## 主要修复

- Fabric 玩家属性改为在玩家构造末尾按需追加 `life_shield`，不再整表替换默认属性；NeoForge 保持 `EntityAttributeModificationEvent` 路径。
- 自动熔炼改为包装原版掉落列表，保留方块经验、平台掉落回调与后续模组处理；高炉或烟熏炉独有配方仍不会触发。
- 额外箭首次伤害被第三方事件或保护规则拒绝后不再重复调用伤害管线，避免一次命中重复触发第三方事件。
- 生物关闭力量重定向时保留原版力量；灵魂加护复活后的 40 tick 内不被恶咒压血；斩杀报告使用真实命中结果；电刀过滤队友、玩家宠物和归属实体。
- 1.21.1 两树随机附魔过滤返回可变 `ArrayList`，避免真实附魔候选列表不可变导致异常。
- NeoForge 检测到 Apotheosis 时整体退让两个铁砧 Mixin；本版未取得对应 1.21.1 Apotheosis JAR，因此实机组合仍标记为待验证。
- 复仇窗口在过期、断线和停服时清理；生命护盾混合吸收池、全局附魔判定矩阵、Spears 与 KubeJS 既有回归通过。

## 验证

- Fabric `clean build` 通过；Fabric 核心自检 68/0。
- NeoForge `clean build` 与 `verifyMixinTargets` 通过；NeoForge 核心自检 63/0。
- NeoForge + SR 2.0.0 + SRA 0.1.3 + Curios 9.5.1 组合自检 29/0。
- Fabric/NeoForge 的 Backported Spears 1.21.1 专项自检各 9/0。
- NeoForge KubeJS 2101.7.2 自检通过；Fabric 1.21.1 不提供 KubeJS 插件。
- Fabric/NeoForge 专用服务端均到达 `Done` 并可正常停止；日志无新增 `InjectionError`、`MixinTransformerError` 或非预期注入冲突。

## 内容规模

- 32 个附魔、99 项配置 / 11 个配置组、网络协议 9，均未变化。
- 无新增配置键、附魔、语言键、注册表类型、数据文件或公开方法签名。

## 安装

### Fabric

1. Minecraft 1.21.1 + Fabric Loader 0.20.1 或更高。
2. 安装 Fabric API。
3. 将 `summy-enchantment-1.4.3+1.21.1.jar` 放入 `mods/`。

### NeoForge

1. Minecraft 1.21.1 + NeoForge 21.1.265 或更高。
2. 将 `summy-enchantment-1.4.3+1.21.1-neoforge.jar` 放入 `mods/`。

升级时只保留一个 Summy Enchantment 版本。

## 兼容边界

- 1.21.1 Apotheosis 铁砧退让代码已接入，但对应版本真实同装、铁砧交易和启动日志仍需后续补测。
- Backported Spears 1.5.0+ 的支持以上游继续使用当前 `pierce` 参数口径为前提；上游未来若改变公式，SE 需要重新核验。
- Fabric 与 NeoForge 功能对等；KubeJS 仅作为 NeoForge 可选依赖，不进入 Fabric 产物。
