# Summy Enchantment 1.4.2

**Minecraft 1.20.1 · Fabric + Forge**

1.4.2 完善 Backported Spears 兼容：1.4.7 继续使用旧版本伤害修正，1.5.0 及以上直接使用上游已修复的基础伤害，同时保留 SE 的完整矛命中和力量Plus结算。

## Backported Spears 1.5.0+

- 上游 1.5.0 已修复玩家 `pierce` 路径重复计算基础伤害。SE 不再对 1.5.0+ 做二次反解。
- SE 的事件、魔剑、嗜血与左键力量Plus继续正常工作。
- 左键目标攻击侧金额保持 `力量倍率 × (基础伤害 + 冷却 × 附魔伤害)`。
- 右键目标金额保持 `基础伤害 + 附魔伤害 + 速度伤害`，不追加力量Plus。
- Backported Spears 1.4.7 继续使用旧公式反解，行为不变。
- 其它未确认版本安全放行，但不会启用 SE 矛结算。

## 验证

- Fabric 与 Forge `clean build` 通过；Forge `verifyMixinTargets` 同时核验 1.4.7 与 1.5.0。
- 两个加载器分别运行 Spears 1.4.7 与 1.5.0 专项客户端自检。
- 1.4.2 候选 JAR 在 Fabric/Forge × Spears 1.4.7/1.5.0 的生产实例中复测通过；KubeJS 右键事件金额在锋利 II 下为 `26.5`，不再遗漏附魔伤害。
- Forge 外部兼容回归为 13 项、失败 0 项；Fabric 原生兼容回归为 5 项、失败 0 项。
- 左键无附魔 / 锋利 II：`5 / 6.5`。
- 蓄力无附魔 / 锋利 II：`25 / 26.5`。
- 左键力量Plus I：`7.5`，不再因版本门禁退回 `5`。
- 魔剑追加伤害、嗜血回复、KubeJS `meleeSettled` 与 Mixin 日志均正常。
- 未安装 Spears 时，Fabric 与 Forge 正式客户端均正常进入测试世界，未发生兼容 Mixin 类加载。
- Backported Spears 1.5.0 与 Apotheosis 7.4.8 同时安装时存在 `EnchantmentHelperMixin` 注入冲突；冲突双方均为外部模组。本次未在无 SE 环境复现，因此不把它归因于 SE，也不将该三模组合列为正式支持门禁。

## 内容规模

- 32 个附魔、99 项配置 / 11 个配置组、网络协议 9，均未变化。
- 无新增配置、语言键、附魔、注册表类型、数据文件或公开方法签名。

## 安装

### Fabric

1. Minecraft 1.20.1 + Fabric Loader 0.18.4 或更高。
2. 安装 Fabric API。
3. 将 `summy-enchantment-1.4.2.jar` 放入 `mods/`。

### Forge

1. Minecraft 1.20.1 + Forge 47.4.10 或更高。
2. 将 `summy-enchantment-1.4.2-forge.jar` 放入 `mods/`。

升级时只保留一个 SE 版本。

## 兼容边界

- Backported Spears 是可选兼容，不是前置。
- `1.5.0+` 的广范围支持以上游继续使用当前 `pierce` 参数口径为前提；上游未来若修改公式，SE 需要重新核验。
- KubeJS 仍为可选依赖；本版不改变公开 API、事件字段或客户端绑定。
