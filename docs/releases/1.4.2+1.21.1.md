# Summy Enchantment 1.4.2+1.21.1

**Minecraft 1.21.1 · Fabric + NeoForge**

这是 Summy Enchantment 1.4.2 的 Minecraft 1.21.1 平台版本。附魔、配置与网络协议和 1.20.1 版本保持功能对等。

## 平台

- Fabric：Loader 0.20.1、Fabric API 0.116.18+1.21.1
- NeoForge：21.1.265
- Java：21
- 网络协议：9，客户端与服务端必须同版本

## 内容

- 32 个附魔
- 99 项配置，分为 11 组
- Fabric 与 NeoForge 功能一致
- KubeJS 仅作为 NeoForge 可选兼容；Fabric 1.21.1 不包含 KubeJS 插件

## 验证

- Fabric 核心自检 36/0
- NeoForge 核心自检 35/0
- NeoForge + SR + SRA 核心自检 38/0
- Backported Spears Fabric / NeoForge 专项均为 9/0
- NeoForge KubeJS 七类事件全部收到，无错误
- 全组合专用服务端启动到 `Done`
- Fabric / NeoForge 正式构建、语言键与附魔数据一致性通过

## 安装

### Fabric

1. Minecraft 1.21.1 + Fabric Loader 0.20.1 或更高。
2. 安装 Fabric API。
3. 把 `summy-enchantment-1.4.2+1.21.1.jar` 放进 `mods/`。

### NeoForge

1. Minecraft 1.21.1 + NeoForge 21.1.265 或更高。
2. 把 `summy-enchantment-1.4.2+1.21.1-neoforge.jar` 放进 `mods/`。

只保留一个 Summy Enchantment 版本。
