# Summy Enchantment 1.4.3

**Minecraft 1.20.1 · Fabric + Forge**

1.4.3 兼容收口版本：修复玩家属性覆盖、掉落与投射物管线、战斗结算及 Apotheosis 铁砧注入冲突；不改变附魔、配置、网络协议或公开 API 规模。

## 主要修复

- Apotheosis 7.4.8 存在时，SE 自动停用两个铁砧 Mixin，由 Apotheosis 接管铁砧成本、扣费和客户端点数显示；移除 Apotheosis 后恢复原有 SE 配置。
- Fabric 玩家属性改为在玩家构造末尾按需追加 `life_shield`，不再替换整张默认属性表，也不会覆盖第三方玩家属性。
- 自动熔炼改为包装原版掉落列表，保留方块经验、平台掉落回调与后续模组处理；高炉或烟熏炉独有配方仍不会触发。
- 额外箭首次伤害被第三方事件或保护规则拒绝后不再重复调用伤害管线，避免一次命中重复触发第三方事件。
- 生物关闭力量重定向时保留原版力量；灵魂加护复活后的 40 tick 内不被恶咒压血；斩杀报告使用真实命中结果；电刀过滤队友、攻击者宠物和归属实体。
- 1.20.1 弩多重射击散射参数改为包装最终调用参数；复仇窗口在过期、断线和停服时清理。
- 生命护盾混合吸收池、真实随机附魔矩阵和既有 KubeJS 服务端自检通过。

## 验证

- Fabric `clean build` 通过；Fabric 完整自检 44/0。
- Forge `clean build` 与 `verifyMixinTargets` 通过，`verifyMixinTargets` 覆盖 29 个 Mixin 文件；Forge 完整自检 46/0。
- Forge + Celestial/Apotheosis/Majrusz 外部矩阵：49/0。
- Fabric/Forge 的 Backported Spears 1.4.7 与 1.5.0 专项自检各 9/0；制造实例左键 `5 / 6.5`、蓄力 `25 / 26.5`、力量Plus I `7.5`。
- Fabric/Forge KubeJS 自检通过；服务端脚本、客户端隔离、七类事件和既有事件契约无错误。
- Fabric/Forge 专用服务端均到达 `Done` 并可正常停止；日志无新增 `InjectionError`、`MixinTransformerError` 或非预期注入冲突。

## 内容规模

- 32 个附魔、99 项配置 / 11 个配置组、网络协议 9，均未变化。
- 无新增配置键、附魔、语言键、注册表类型、数据文件或公开方法签名。

## 安装

### Fabric

1. Minecraft 1.20.1 + Fabric Loader 0.18.4 或更高。
2. 安装 Fabric API。
3. 将 `summy-enchantment-1.4.3.jar` 放入 `mods/`。

### Forge

1. Minecraft 1.20.1 + Forge 47.4.10 或更高。
2. 将 `summy-enchantment-1.4.3-forge.jar` 放入 `mods/`。

升级时只保留一个 Summy Enchantment 版本。

## 兼容边界

- Apotheosis 铁砧退让按模组存在检测，不按版本白名单；本轮 1.20.1 实机验证版本为 Apotheosis 7.4.8。
- Backported Spears 1.5.0+ 的广范围支持以上游继续使用当前 `pierce` 参数口径为前提；上游未来若改变公式，SE 需要重新核验。
- KubeJS 仍为可选依赖；本版不改变公开 API、事件字段或客户端绑定。
