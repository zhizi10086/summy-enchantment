# Summy Enchantment 1.4.1

**Minecraft 1.20.1 · Fabric + Forge**

1.4.1 是兼容性修复版本，解决 SE 与 Twilight Dusk、Farmer's Delight 组合中暴露的两处 Mixin 固定常量冲突。

## 轻盈与 Twilight Dusk

- SE 不再与 Twilight Dusk 的幻影箭重力 `@ModifyConstant` 抢占同一个 `0.05` 常量。
- 轻盈改为包装箭矢 `tick` 的最终纵向速度写入，读取其它模组处理后实际准备施加的重力，再乘 SE 轻盈倍率。
- Twilight Dusk 的幻影箭半重力与 SE 轻盈按乘算共存，双方效果均保留。

## 大胃袋与其它饥饿容量修改

- SE 不再替换饥饿封顶的固定 `20` 常量。
- 饥饿值封顶改为包装 `Math.min` 结果，“还能吃”改为包装原返回值。
- 其它模组已经扩展的容量不会被降低；SE 大胃袋与外部容量取较高值共存。

## 内容规模

- 32 个附魔、99 项配置、11 个配置组、网络协议 9，均未变化。
- 无新增配置、语言键、附魔、注册表类型或数据文件。
- Fabric / Forge 功能一致，仅映射名与客户端实现类不同。

## 验证

- Fabric 与 Forge `clean build` 通过。
- Forge `verifyMixinTargets` 29 个文件全绿。
- Forge 真实客户端使用官方 Farmer's Delight `1.20.1-1.3.4` 与 Twilight Dusk `1.2fix1`（连同 Twilight Forest 4.3.2508、Curios 5.14.1 前置）完成完整自检，`[SE-DEVCHECK]` 共 19 项、失败 0 项。
- 日志确认 SE 的 `PersistentProjectileEntityMixin`、Twilight Dusk 的 `PhantomArrowGravityMixin`、SE 的 `HungerManagerMixin` 与 Farmer's Delight 的 `NourishmentAlwaysEatMixin` 均成功应用，无 `already redirected`、`Critical injection failure` 或 Mixin apply 失败。
- 普通骑士箭单 tick 纵向速度为 `-0.05`，幻影箭为 `-0.025`；轻盈 2 级在两类箭上均将该速度再乘 0.5，证明 Twilight Dusk 半重力与 SE 轻盈乘算共存。
- 大胃袋 5 级实际可达 40 点饥饿值，0 → 30 → 40 的封顶有效且满值时 `needsFood=false`；Farmer's Delight 的滋养效果在 40 点时仍允许进食。

## 安装

### Fabric

1. Minecraft 1.20.1 + Fabric Loader 0.18.4 或更高。
2. 安装 Fabric API。
3. 将 `summy-enchantment-1.4.1.jar` 放入 `mods/`。

### Forge

1. Minecraft 1.20.1 + Forge 47.4.10 或更高。
2. 将 `summy-enchantment-1.4.1-forge.jar` 放入 `mods/`。

升级时只保留一个 SE 版本。
